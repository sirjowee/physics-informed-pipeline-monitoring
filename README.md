## This repository is a reference re-implementation of the methods published in:

Adegboye, Komolafe & Joseph, “Physics-Aware ML Models for Pipeline Leak Detection and Quantification,” IJSRED 7(6), 2024.
Adegboye, Komolafe & Joseph, “Electromagnetic Signal Classification Using Deep Learning for Pipeline Structural Health Monitoring,” IJSRED 7(6), 2024.

The original development repository is no longer available. This code was written from scratch by Ibrahim M. Joseph (third author on both papers) beginning October 26, 2026, to reproduce the published experiments. All results here are on synthetic/simulated data, as in the papers. Reproduced results are reported in RESULTS.md alongside the published figures, including where they differ.
