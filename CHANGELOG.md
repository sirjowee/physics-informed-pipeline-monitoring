# Changelog

All notable changes to this re-implementation are recorded here. Dates are the dates the work was done; nothing is backdated.

## v0.1-rfe — 2026-11-03

### 2026-11-03 — Phase 7, release
- RESULTS.md: summary of reproduction at the top, status line, paper-2 known gaps (§2.6), remaining note cells filled.
- Tagged `v0.1-rfe`.

### 2026-11-03 — Phase 6, reproduce-all and docs
- Added `scripts/reproduce_all.py` and a `Makefile` (`make reproduce`, `make reproduce-full`, `make test`, `make lint`); default run 2.0 min on an M1 CPU.
- README "How to reproduce" completed with commands, versions, runtime, seed and the reproducibility limit.
- `--full` for the leak generator now scales the scenario count only (the 300 s run length is tied to the feature and physics windows); evaluation derives the feature size from the data.
- Results and figures regenerated by the canonical `make reproduce` run; RESULTS.md §1.1, §1.2, §1.4 (λ row) and §1.5 updated to that run, with the previous run kept as a second sample of run-to-run variation.

### 2026-11-03 — Phase 5, leak-detection evaluation
- Added `leak_detection/evaluate.py` and `scripts/leak_evaluate.py`: single test-set evaluation of PINN, black-box and RTTM (accuracy, precision, recall, ROC-AUC, localisation MAE, rate MAPE, per-regime breakdown, noise-robustness sweep), `results/leak_metrics.json` and four figures.
- RESULTS.md §1.1 and §1.2 "Reproduced" columns filled; §1.5 dated note stating that the published figures were not reproduced, with likely causes; §1.6 known gaps extended.

### 2026-11-03 — Phase 4, PINN and baselines
- Added `leak_detection/features.py` (binned sensor features, targets), `physics.py` (scaled two-fluid residuals shared by training and tests), `pinn.py` (encoder + heads + field network, data / sensor-fit / physics losses, Adam training, save/load), `rttm.py` (solver-based no-leak model, residual thresholding, friction-based localisation, mass-imbalance rate).
- Added `scripts/leak_train.py` (λ_phys sweep and RTTM threshold on the validation set; writes `results/leak_selection.json` and weights) and tests (steady residuals, sink lowers residual, features, training reduces loss, determinism, RTTM).
- RESULTS.md §1.3 network/loss/derivatives/optimizer/framework rows and §1.4 model rows filled; §1.5 dated note. A baseline-deviation feature variant was tried and rejected on validation. Training with λ_phys > 0 is not bit-reproducible on this machine (recorded in RESULTS.md §1.4); all sampling was moved to NumPy and op determinism enabled, which makes the λ = 0 run exactly reproducible.

### 2026-11-03 — Phase 3, leak-detection synthetic data generator
- Added `leak_detection/data/config.py` (geometry, fluids, regimes, simulation and dataset settings), `two_fluid_solver.py` (batched 1-D isothermal two-fluid finite-volume solver with leak sink, friction and regime-dependent drag), `scenarios.py` (scenario sampling, sensor noise, event-based split, npz I/O).
- Added `scripts/leak_generate_data.py` (default 240 scenarios, `--full` 720 × 600 s) and the sensor-example figure; tests for shapes, mass conservation, steady residual, leak effect, determinism, sampler and split.
- RESULTS.md §1.3 "Implemented here" and §1.4 data rows filled; §1.5 dated note.

### 2026-11-03 — Phase 2, SHM 1D-CNN
- Added `shm_classification/model.py` (published architecture), `train.py` (Adam 0.001, batch 16, 50 epochs, early stopping on an internal validation split), `evaluate.py` (clean and noisy test metrics, confusion matrices, training curves), `scripts/shm_train_eval.py`, tests.
- RESULTS.md §2.1, §2.2, §2.3, §2.4 and §2.5 filled; Table 2 transcription corrected to the paper's printed values and the paper's text/table inconsistency noted.
- Committed `results/shm_metrics.json` and the two final figures.

### 2026-11-03 — Phase 1, SHM S11 dataset generator
- Added `shm_classification/data/s11_simulator.py`: 91-point 1–10 GHz grid, four-class analytic |S11| model (resonance shift, damping, bandwidth change), Gaussian noise injection, per-trace z-score, seeded stratified 80/20 split.
- Added `scripts/shm_generate_data.py` (writes `data/shm/s11_dataset.npz` and the example-trace figure) and tests.
- RESULTS.md §2.3 "Implemented here" and §2.4 parameter table filled for the data side.

### 2026-11-03 — Phase 0, housekeeping
- Renamed `requirments.txt` to `requirements.txt` and pinned versions.
- Rewrote README with title, provenance paragraph, author line, paper links, status and reproduction sections.
- Added `pyproject.toml`, `.gitignore`, `src/pipeline_monitoring/` package skeleton, `tests/`, `scripts/`, `figures/`, and GitHub Actions CI (ruff + pytest).
